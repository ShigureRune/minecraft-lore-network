# Minecraft Lore Network

Minecraftの世界観・考察を探索する非公式知識グラフ。v0.1.0（関係図 v1.03 / 考察MD v3.21）：65項目・92関係線。独自仮説は公式設定と区別しています。

公開予定: https://shigurerune.github.io/minecraft-lore-network/

## 公開設定
Settings → Pages → Deploy from a branch → main / (root) → Save。

## データ
- `index.html`: 単体動作するサイト
- `graph.json`: ノードと関係線のデータ
- `minecraft_lore_map.svg`: 閲覧用相関図
- `minecraft_lore_map.dot`: 編集用グラフソース
- `template.html`: サイトテンプレート

文字色＝分野、下線色＝媒体、左の記号＝次元。実線＝記録された仕様・描写、破線＝独自仮説・比較。存在する次元と起源は区別。全仮説の収録および一次資料の再検証は未完了。研究MD全文・参考画像は公開対象外。
