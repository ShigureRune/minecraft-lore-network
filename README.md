# Minecraft Lore Network

Minecraftの世界観・考察を探索する非公式知識グラフ。v0.4.0（関係図 v1.06 / 考察MD v3.21）：194項目・309関係線。独自仮説は公式設定と区別しています。

公開URL: https://shigurerune.github.io/minecraft-lore-network/

## 公開設定
Settings → Pages → Deploy from a branch → main / (root) → Save。

## データ
- `index.html`: 単体動作するサイト
- `graph.json`: ノードと関係線のデータ
- `minecraft_lore_map.svg`: 閲覧用相関図
- `minecraft_lore_map.dot`: 編集用グラフソース
- `template.html`: サイトテンプレート

文字色＝分野、下線色＝媒体、左の記号＝次元。実線＝記録された仕様・描写、破線＝独自仮説・比較。存在する次元と起源は区別。H01〜H61の全仮説番号を関係線に収録（全詳細・全資料の網羅ではない）。一次資料の再検証は未完了。研究MD全文・参考画像は公開対象外。

## v0.4.0 表示整理
項目・関係の内容は維持。`layout.json` は自由配置と経路・ラベル位置の保存データ。通常は説明を隠し、選択した項目または経路の線だけ説明を表示。「関連だけ」で周辺以外を非表示。静的SVGでは混雑する関係ラベルは非表示（titleで内容を確認可能）。自動配置のため交差や近接は残ることがあります。

## v0.5.0 探索モード
初期画面は古代ビルダー文明を起点に、直接関係する項目を資料記録と独自仮説に分けて表示。項目を押すと探索地点を移動できる。全体図は右上で切り替え、従来の194項目・309関係線を維持。関係図データはv1.06のまま。

## v0.6.0 関連度による配置（図 v1.07）
直接の関係を引力、共通の関連項目を弱い引力、同分野を補助的な引力として配置。記録された関係を仮説より少し強く重み付けし、文字の衝突を避ける。距離はネットワーク上の近さで、仮説の正しさや公式設定の確度ではない。データ194項目・309関係線は維持。全体図の平均直接関係距離は約884→497（SVG座標単位）。
